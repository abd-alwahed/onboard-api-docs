Live Vehicles API واجهة التتبع المباشر للمركبات

Connect to the Onboard platform and receive the live location and status of your vehicles in real time.

اربط نظامك مع منصة Onboard واستقبل الموقع والحالة المباشرة لمركباتك لحظة بلحظة.

1Login API

Send email + password, get an access token.

أرسل البريد وكلمة المرور، واستلم token.

2WebSocket

Open the socket with the token and receive vehicle updates continuously.

افتح اتصال WebSocket بالتوكن واستقبل تحديثات المركبات بشكل مستمر.

Getting credentialsالحصول على حساب

🔑

You need a username (email) and password to use this API. They are issued by Onboard — contact the Onboard team and they will create an API account for you and send you its credentials.

لاستخدام هذه الواجهة تحتاج اسم مستخدم (email) وكلمة مرور. هذه البيانات تصدرها شركة Onboard — تواصل مع فريق Onboard وسيقومون بإنشاء حساب API خاص بك وإرسال بياناته إليك.

onboardsaudi.com

In all the examples on this page, replace YOUR_EMAIL and YOUR_PASSWORD with the credentials you received.

في كل الأمثلة الموجودة بهذه الصفحة، استبدل YOUR_EMAIL و YOUR_PASSWORD بالبيانات التي استلمتها.

⚠️

Keep your credentials and token on your server. Do not ship them inside a public website or mobile app.

احفظ بيانات الدخول والتوكن على السيرفر الخاص بك، ولا تضعها داخل موقع عام أو تطبيق جوال.

1. Login API

Sends the user's email and password and returns the access token used to open the WebSocket connection.

ترسل البريد الإلكتروني وكلمة المرور للمستخدم، وترجع التوكن (access token) الذي يُستخدم لفتح اتصال WebSocket.

POST https://my.onboardsaudi.com/backend/api/login

passwordstringYesنعم The user's password.كلمة المرور.

Fieldالحقل Typeالنوع Descriptionالوصف

data.expires_ininteger Token validity in seconds (31535999 ≈ one year). After it expires, log in again.مدة صلاحية التوكن بالثواني (31535999 ≈ سنة). بعد انتهائها سجّل الدخول من جديد.

2. Live Vehicles WebSocket

After login, open a WebSocket connection with the token. The server pushes an update message every time a vehicle's position or status changes.

بعد تسجيل الدخول افتح اتصال WebSocket بالتوكن. السيرفر يرسل رسالة تحديث كلما تغيّر موقع أو حالة أي مركبة.

ItemالبندValueالقيمة
ProtocolالبروتوكولWebSocket over TLS (wss://)WebSocket مشفّر (wss://)
Hostmy.onboardsaudi.com
Port443 — the default HTTPS port, so it is not written in the URL443 — المنفذ الافتراضي لـ HTTPS لذلك لا يُكتب في الرابط
Path/ws/ — keep the slash at the end/ws/ — مع الإبقاء على الشرطة في النهاية
Authenticationالمصادقةtoken query parameter — the token from the Login APIبارامتر token في الرابط — التوكن من Login API
Message formatصيغة الرسائلJSON (UTF-8 text)
DirectionالاتجاهServer → client. The client does not need to send any message after connecting.من السيرفر ← إلى العميل. لا يحتاج العميل لإرسال أي رسالة بعد الاتصال.

Connection URLرابط الاتصال

WSS wss://my.onboardsaudi.com/ws/?token=<ACCESS_TOKEN>

Replace <ACCESS_TOKEN> with data.token from the Login API. No request body and no headers are needed.

استبدل <ACCESS_TOKEN> بقيمة data.token من Login API. لا يوجد Body ولا Headers.

Parameterالبارامتر Typeالنوع Requiredإلزامي Descriptionالوصف
tokenstringYesنعم The access token returned by the Login API (data.token). The server uses it to identify the user and returns only the vehicles that user has permission to see. If the token is invalid or expired, the connection is closed with code 4401. التوكن الراجع من Login API (data.token). يستخدمه السيرفر لمعرفة المستخدم ويرجع فقط المركبات المسموح له برؤيتها. إذا كان التوكن غير صالح أو منتهي يُغلق الاتصال بالكود 4401.

Message formatشكل الرسالة

Each message describes one vehicle. It has a type ("update"), a position object and a device object. Use device.name to match updates to the same vehicle.

كل رسالة تخص مركبة واحدة، وتحتوي type (قيمته "update") وكائن position وكائن device. استخدم device.name لربط التحديثات بنفس المركبة.

2.1 position — location of each vehicleموقع المركبة

FieldالحقلTypeالنوعMeaningالمعنى
latitudenumber Latitude in decimal degrees (WGS84, the standard GPS system). Example: 24.9748.خط العرض بالدرجات العشرية (WGS84 نظام GPS القياسي). مثال: 24.9748.
longitudenumber Longitude in decimal degrees (WGS84). Example: 46.6950.خط الطول بالدرجات العشرية (WGS84). مثال: 46.6950.
speednumber Current speed as reported by the tracking device. 0 means the vehicle is not moving.السرعة الحالية كما يرسلها جهاز التتبع. 0 تعني أن المركبة لا تتحرك.
ignitioninteger (0 / 1) Engine ignition (key) state. 1 = ON (engine running), 0 = OFF.حالة تشغيل المحرك (المفتاح). 1 = يعمل، 0 = مطفأ.
motioninteger (0 / 1) Whether the device detects movement. 1 = moving, 0 = stopped. A vehicle can have ignition = 1 and motion = 0 (engine on but standing still, e.g. at a traffic light).هل يكتشف الجهاز أن المركبة تتحرك. 1 = تتحرك، 0 = متوقفة. ممكن تكون ignition = 1 و motion = 0 (المحرك يعمل لكن المركبة واقفة، مثلاً عند إشارة مرور).
📍

Latitude and longitude are sent with very high precision. Rounding to 6 decimal places (about 10 cm) is enough for display.

الإحداثيات تُرسل بدقة عالية جداً (أرقام عشرية كثيرة). التقريب إلى 6 خانات عشرية (حوالي 10 سم) كافٍ للعرض.

2.2 device — identity and status of each vehicleهوية المركبة وحالتها

FieldالحقلTypeالنوعMeaningالمعنى
namestring Display name of the vehicle: usually the plate number (e.g. "7650 KAR") or the fleet code (e.g. "SR111").اسم المركبة المعروض: غالباً رقم اللوحة (مثل "7650 KAR") أو كود الأسطول (مثل "SR111").
statusstring Current status — one of the values below.الحالة الحالية — إحدى القيم في الجدول التالي.

2.3 status valuesالقيم

ValueالقيمةMeaningالمعنى
onlineThe tracking device is connected and sending data now.جهاز التتبع متصل ويرسل بيانات الآن.
parkedThe device is sending data, but the vehicle is parked.الجهاز يرسل بيانات لكن المركبة مركونة.
offlineThe device was connected before but is not sending data now.الجهاز كان متصلاً سابقاً لكنه لا يرسل بيانات الآن.
unknownNo recent data from the device, so its status cannot be determined.لا توجد بيانات حديثة من الجهاز، لذلك لا يمكن تحديد حالته.
